## Что такое Kairos

Kairos объединяет повседневные сетевые операции в одном приложении для строки меню. Оно определяет текущее окружение по имени Wi-Fi, диапазону IP и характеристикам DNS, а затем автоматически применяет нужные настройки прокси и DNS, запускает или завершает приложения. Также доступны инструменты DNS, поиск IP по нескольким источникам, проверка рисков конфиденциальности и настройка Mihomo.

**Kairos не заменяет сетевые настройки macOS или ваш прокси-клиент.** Приложение связывает уже используемые инструменты и предоставляет быстрый доступ к диагностике.

## Состояние проекта

> **Готовится первая публичная бета-версия**

Функции приложения и проверка сборки arm64 реализованы. Для push в main и pull request запускаются лёгкие проверки автоматизации. Если изменены только `README.md`, `docs/`, `LICENSE` или `AGENTS.md` и публикация отключена, сборка macOS пропускается; для остальных изменений собираются неподписанные App и Helper. Публикация `0.1.0-beta.1` сейчас отключена.

## Системные требования

| Параметр | Значение |
|---|---|
| Минимальная версия | macOS 26.0 Tahoe |
| Процессор | Apple Silicon (arm64) |
| Тип приложения | Несандбоксированное приложение LSUIElement для строки меню |
| Привилегированный компонент | LaunchDaemon на основе `SMAppService` для управления системным DNS |
| Распространение | Один подписанный Apple Development, но не нотариально заверенный DMG в GitHub Releases |

## Установка и выпуски

Каждый выпуск GitHub содержит один файл `Kairos-<версия>.dmg`. Откройте DMG и перетащите `Kairos.app` в `Applications`. Выпуски подписываются сертификатом Apple Development, но не проходят нотариальное заверение Apple. Перед первым запуском удалите атрибут карантина загрузки:

```bash
sudo xattr -rd com.apple.quarantine /Applications/Kairos.app
```

Для управления системным DNS зарегистрируйте Helper в настройках Kairos и подтвердите LaunchDaemon в Системных настройках по запросу macOS.

Push в main и pull request всегда запускают лёгкие проверки автоматизации релиза. Изменения за пределами `README.md`, `docs/`, `LICENSE` и `AGENTS.md` дополнительно собирают и проверяют неподписанные arm64 App, Helper и LaunchDaemon bundle; включение публикации также принудительно запускает эту полную проверку. DMG публикуется только после успешного CI в main, при `release: true`, для ещё не опубликованной версии и при наличии единственного непустого раздела той же версии в [`CHANGELOG.md`](../CHANGELOG.md).

Поддерживаются версии `x.y.z`, `x.y.z-alpha.n` и `x.y.z-beta.n`. Суффиксы Alpha/Beta используются в tag, Release, DMG и Changelog; App и Helper получают соответствующую числовую маркетинговую версию `x.y.z`.

## Сборка из исходного кода

Требуются macOS 26.0 или новее, Xcode 26 или новее и Apple ID. Откройте `Kairos.xcodeproj`, выберите свою команду разработчика, обновите требования подписи XPC в `App/Services/DNSManager.swift` и `KairosHelper/main.swift` под свой Team ID, затем соберите scheme `Kairos`.

## Ключи API

Поиск IP и проверки конфиденциальности используют несколько внешних сервисов. Базовые функции доступны без настройки всех провайдеров; при большом количестве запросов можно добавить собственные ключи API в настройках.

| Сервис | Бесплатный лимит | Назначение |
|---|---|---|
| [IPinfo](https://ipinfo.io) | 50 000 запросов в месяц | Владелец и местоположение IP |
| [ipapi.is](https://ipapi.is) | 1 000 запросов в день | Информация об IP |
| [AbuseIPDB](https://www.abuseipdb.com) | 1 000 запросов в день | Оценка злоупотреблений и риска |
| [IP2Location](https://www.ip2location.com) | Есть бесплатный тариф | Точное местоположение IP |
| [ipregistry](https://ipregistry.co) | 10 000 бесплатных запросов | Сводная информация об IP |

## Основные решения

- Нативный интерфейс строки меню и системная интеграция на SwiftUI и AppKit.
- Разделение правил сценариев, наблюдения за сетью и выполняемых действий.
- Отдельно подписанный Helper для системного DNS со взаимными требованиями к подписи кода.
- Сценарии, DNS, ключи API и экспортируемые настройки контролируются пользователем и хранятся на Mac.
- Публикация только после CI, явного переключателя manifest, соответствующих заметок и проверки App, Helper и DMG.
